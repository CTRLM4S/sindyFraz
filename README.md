# SINDY FRAZ — Cuenta regresiva

Sitio estático para GitHub Pages. No requiere Node, PHP ni compilación.

## Archivos
- `index.html`: contenido de la página
- `style.css`: estética punk fotocopiada responsive
- `script.js`: cuenta regresiva y pitido activable
- `assets/sindy-fraz-logo.png`: logo de la banda

## Publicar en GitHub Pages
1. Creá un repositorio en GitHub (por ejemplo, `sindy-fraz-countdown`).
2. Subí todos los archivos y la carpeta `assets`, manteniendo la estructura.
3. Entrá en **Settings → Pages**.
4. En **Build and deployment**, elegí **Deploy from a branch**.
5. Seleccioná la rama `main` y la carpeta `/ (root)`, y guardá.
6. Esperá a que GitHub publique el sitio y compartí el enlace que aparece en esa sección.

La cuenta regresiva apunta al 30 de octubre de 2026 a las 15:00, hora de Argentina (UTC−3).
El audio requiere que la persona toque el botón **ACTIVAR PITIDO**, debido a las restricciones de los navegadores.
